# 🎓 College Management System

A Python-based College Management System with a professional graphical user interface built using Tkinter.

The application allows you to manage students, teachers, student grades, and teacher salaries while storing the data locally in a JSON file.

## ✨ Features

- 👨‍🎓 Student registration
- 👨‍🏫 Teacher registration
- 📋 View student records
- 📋 View teacher records
- 🔎 Search students
- 📝 Add and update student grades
- 💰 Update teacher salaries
- 📊 Dashboard with statistics
- 💾 JSON-based data storage
- ✅ Input validation
- ⚠️ Error and success messages
- 🎨 Professional Tkinter GUI

## 🛠️ Technologies Used

- Python
- Tkinter
- JSON
- Object-Oriented Programming (OOP)
- Abstract Base Classes (ABC)
